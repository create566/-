六、8 种检测器矩阵 Detectors
▼
🌐
http_health
http_status
HTTP 健康端点检测 — 检查 /health 返回 2xx

💻
local_cpu
cpu_usage_percent
本机 CPU 使用率检测 — psutil.cpu_percent()

🧠
local_memory
memory_usage_percent

local_disk
disk_usage_percent

memory_usage_percent

七、系统生命周期 & 健康分机制 Lifecycle
▼
📝
注册系统
POST /api/systems
→
🟢
active · 运行中
定时检测中
健康分 0~100
⏸️ 暂停 → paused
停止调度，保留配置
▶️ 恢复 → active
重新启动定时检测
💚 健康分机制
初始 → 100 分 正常检测 → +5 分（上限100） warning → -10 分 critical → -20 分 💚≥90 健康 💛≥70 良好 🧡≥50 注意 ❤️<50 危险
