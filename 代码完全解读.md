## 第一部分：项目是什么

一句话：**一个 Web 应用，你告诉它"监控哪些东西"，它就会定时自动检测，发现异常后用 AI 分析根因并推送到飞书**。

```
你注册一个监控系统 → 调度器每 30 秒跑一次 → Agent 执行检测器 → 正常就加分，异常就飞书推送+存故障
```

### 技术栈速览

| 组件 | 用途 |
|------|------|
| FastAPI | Web 框架，提供 API + 静态页面 |
| LangGraph | AI Agent 编排框架（让 LLM 按步骤思考） |
| LangChain | LLM 调用封装（统一 vLLM/Ollama/DashScope/DeepSeek） |
| APScheduler | 定时任务调度 |
| SQLAlchemy | MySQL ORM |
| pymilvus | 向量数据库客户端 |
| psutil | 本机 CPU/内存监控 |
| httpx | HTTP 异步请求 |
| pymysql | MySQL 直连检测 |
| redis-py | Redis 直连检测 |
| lark-oapi | 飞书 API SDK |
| loguru | 日志 |

```python
# detectors/registry.py
class DetectorRegistry:
    _detectors: Dict[str, Type[BaseDetector]] = {}  # 类名→类
    _instances: Dict[str, BaseDetector] = {}         # 缓存已创建的实例

    @classmethod
    def get_or_create(cls, name, config=None):
        cache_key = f"{name}_{hash(str(config))}"
        if cache_key in cls._instances:
            return cls._instances[cache_key]    # 缓存命中直接返回
        detector_cls = cls._detectors.get(name)
        if detector_cls is None:
            return None
        instance = detector_cls(config)
        cls._instances[cache_key] = instance    # 缓存起来
        return instance
```

```python
# alert/pipeline.py:25
async def run(self, system, auto_push=True):
    system_id = system["id"]

    # ① 冷却检查（60秒内同一系统不重复）
    now = datetime.now().timestamp()
    if auto_push and system_id in self._last_alert:
        if now - self._last_alert[system_id] < 60:
            return None  # 跳过

    # ② 加载历史数据（最近 60 条）
    history = store.get_check_history(system_id, limit=60)

    # ③ Agent 智能检测 —— 核心！
    result = await agent_graph.ainvoke({
        "system_id": system_id,
        "system_name": system_name,
        "detectors": system.get("detectors", []),
        "history": history,
        "phase": "checking",          # 初始阶段 = 检测
        "plan": [],                    # 空计划，等 Planner 生成
        "current_step": 0,
        "results": [],
        "anomalies": [],
        ...
    }, config={"configurable": {"thread_id": system_id}})
```

`agent_graph.ainvoke()` 会触发 LangGraph 的状态机，按照**图（Graph）**定义的节点顺序自动流转。

### 3.3 LangGraph Agent 图结构

```python
# agent/graph.py:17
def build_agent_graph(config):
    workflow = StateGraph(AgentState)     # AgentState = 共享状态字典

    workflow.add_node("planner", planner)     # 节点1：规划
    workflow.add_node("executor", executor)   # 节点2：执行
    workflow.add_node("replanner", replanner) # 节点3：复盘

    workflow.set_entry_point("planner")       # 起始 = planner

    workflow.add_edge("planner", "executor")  # planner → executor

    # executor 条件分支
    workflow.add_conditional_edges(
        "executor", should_continue_execution,
        {"continue": "executor",   # 还有步骤 → 循环
         "review": "replanner"}    # 全执行完 → replanner
    )

    # replanner 条件分支
    workflow.add_conditional_edges(
        "replanner", decide_next,
        {"continue": "planner",    # 需要深度诊断 → 重新规划
         "done": END}              # 有结论了 → 结束
    )

    return workflow.compile(checkpointer=MemorySaver())
```

### 3.5 Executor 执行器

```python
# agent/executor.py:8
async def executor(state: AgentState) -> dict:
    plan = state.get("plan", [])
    current_step = state.get("current_step", 0)

    if current_step >= len(plan):
        return {"results": results}  # 全部执行完

    step = plan[current_step]
    action = step.get("action")      # 如 "local_cpu"

    # ① 从注册中心拿检测器实例
    detector = DetectorRegistry.get_or_create(action, config=...)

    # ② 执行检测
    result = await detector.check(
        system_id=...,
        endpoint=...,
        thresholds=step["params"]["thresholds"],
    )

    # ③ 如果是异常，加入 anomalies 列表
    if result.is_anomalous:
        anomalies.append(run_result)

    return {
        "results": results,
        "anomalies": anomalies,
        "current_step": current_step + 1,  # 前进到下一步
    }
```

看一个具体的：`LocalCPUDetector`

```python
# detectors/local.py:47

    name = "local_cpu"
    metric_name = "cpu_usage_percent"

    async def check(self, system_id, system_name, endpoint, thresholds, auth):
        import psutil
        value = round(psutil.cpu_percent(interval=1), 1)  # 取 1 秒内 CPU 均值

        #   value >= critical(80) → "critical"
        #   value >= warning(60)  → "warning"

            metric_name="cpu_usage_percent",
```

### 3.7 Replanner 复盘器

```python
# agent/replanner.py:11
async def replanner(state: AgentState) -> dict:
    results = state.get("results", [])
    anomalies = state.get("anomalies", [])
    history = state.get("history", [])

    # 没有异常 → 正常
    if not anomalies:
        return {"severity": "normal", "phase": "done"}

    # ① 本地快速毛刺过滤
    quick_judgment = _quick_judge(anomalies, history)
    if quick_judgment == "normal":
        return {"severity": "normal", "phase": "done"}  # 毛刺，不告警

    # ② LLM 生成诊断报告（含知识库RAG）
    return await _generate_report(state, llm, anomalies, results, history_text)
```

#### 毛刺过滤逻辑（`_quick_judge`）

```python
# agent/replanner.py:141
def _quick_judge(anomalies, history):
    for a in anomalies:
        detector = a.get("detector_name", "")
        value = a.get("metric_value", 0)

        # 取该检测器的历史值
        hist_values = []
        for h in history:
            if h.get("detector_name") == detector:
                hist_values.append(h.get("metric_value", 0))

        if len(hist_values) >= 4:
            recent = hist_values[-4:]
            avg_recent = sum(recent) / len(recent)

            # 前 4 次都正常（均值<50），只有这次突然 >80 → 毛刺
            if avg_recent < 50 and value > 80:
                if len(anomalies) == 1:   # 只有这一个异常
                    return "normal"        # 过滤掉
    return "anomaly"
```

## 第六部分：LLM 工厂（统一接口）

```python
# core/llm_factory.py
class LLMFactory:
    PROVIDER_DEFAULTS = {
        "vllm":      {"base_url": "http://localhost:8000/v1",     "model": "Qwen2.5-7B-Instruct"},
        "ollama":    {"base_url": "http://localhost:11434/v1",    "model": "qwen2.5:7b"},
        "dashscope": {"base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1", "model": "qwen-plus"},
        "openai":    {"base_url": "https://api.deepseek.com",     "model": "deepseek-chat"},
    }

    @staticmethod
    def create_chat_model(...):
        # 统一创建 ChatOpenAI 实例
        return ChatOpenAI(model=model, base_url=base_url, api_key=api_key, ...)
```

所有 provider 都走 OpenAI 兼容 API，只是 `base_url` 和 `model` 不同。

**LLM 在 4 个地方被调用：**

| 位置 | 用途 | temperature | timeout | max_tokens |
|------|------|-------------|---------|------------|
| planner.py:12 | 制定检测顺序/诊断计划 | 0.3 | 20s | 4096 |
| replanner.py:14 | 生成诊断报告 | 0.3 | 45s | 800 |
| monitoring.py:787 | 飞书自由对话兜底 | 默认 | 30s | 500 |
| main.py:39 | 启动时 LLM 验证 | 默认 | 60s | 5 |
